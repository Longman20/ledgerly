# Ledgerly

This is a simple expense tracker for small businesses

## Built with

- React
- Vite
- Vitest
- React Testing Library
- ESLint
- Prettier

## Getting started

```bash
git clone https://github.com/Longman20/ledgerly.git
cd ledgerly
npm install
npm run dev
```

Then open the local URL that Vite prints in your terminal.

## Testing

Testing runs your test in watch mode.
Run it with:

```bash
npm run test
```

## Scripts available

| Command                | What it does                                                                        |
| ---------------------- | ----------------------------------------------------------------------------------- |
| `npm run dev`          | start the development server.                                                       |
| `npm run lint`         | to check if your code has any errors.                                               |
| `npm run format:check` | only checks your files and fails if any file is unformatted.                        |
| `npm run format`       | fixes your files and rewrites them into the correct style. You run it while coding. |
| `npm run test`         | runs the tests in watch mode.                                                       |
| `npm run test:run`     | runs the tests once.                                                                |
| `npm run build`        | creates the production-ready version in the dist folder.                            |

The project is still in its early development.
